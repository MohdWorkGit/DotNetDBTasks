Troubleshooting

Every known problem, what causes it, and what to check. Type a word from the error to narrow the list. The API's own log is in logs\log-*.txt next to it; IIS start-up failures are in Event Viewer → Application.

التثبيت والتشغيل

حل المشكلات

كل مشكلة معروفة، وسببها، وما يجب فحصه. اكتب كلمة من رسالة الخطأ لتضييق القائمة. سجل الـAPI في logs\log-*.txt بجانبه، وأخطاء بدء IIS في Event Viewer ← Application.

Problems and checks

Start-up and sign-in

ProblemCheck
The API does not startIs the database running? Is the connection string in appsettings.json right? After an upgrade, ORA-00955 or ORA-01430 in the log means a schema change stopped half-way: see the Oracle rules and restore the backup.
Sign-in failsCan the server reach the LDAP or AD host? Are the bind account and the attribute names right (sAMAccountName for AD, uid for OpenLDAP)?
Sign-in fails on a Docker stack first started as BayanThe LDAP volumes still hold dc=bayan,dc=local. Remove the ldap_data and ldap_config volumes only, never down -v.
Stored database passwords cannot be readEncryption:Key changed between builds. It must never change.
Too many sign-in attempts (HTTP 429)Sign-in is limited per address (Auth:Login:PermitLimit, 10 a minute by default). Wait a minute.
The site is blank or shows 404 (nginx)Does nginx's root point at the client's browser/ folder?
/api calls return 502 (nginx)Is the API actually running on port 5000?
CORS errorsCors:AllowedOrigins must match the exact address in the browser. (Not used on IIS, where everything is one address.)

IIS

ProblemCheck
HTTP 500.19, configuration lockedThe authentication sections are not unlocked: run the two appcmd unlock commands in Windows sign-in, or set authentication in IIS Manager.
HTTP 500.19 naming applicationInitializationThe Application Initialization feature is missing, so IIS cannot read web.config. Install it (prerequisite 2). Not the same as the locked-configuration 500.19.
HTTP 500.30 or 502.5 at startHosting Bundle missing, app pool not set to No Managed Code, or the app crashed while starting: see Event Viewer → Application and logs\.
Import-Module WebAdministration failsIIS Management Scripts and Tools missing: Install-WindowsFeature Web-Scripting-Tools.
Windows sign-in asks for a passwordSite opened by IP instead of host name, host not in the Local Intranet zone, or no SPN for a custom pool account.
The sign-in form appears on a domain computerAuth:EnableSso is still false, or the user signed out earlier in this browser session (the automatic attempt waits until the browser is closed).

Scheduled tasks and results

ProblemCheck
Every scheduled export runs twiceA web garden or a second site: processModel.maxProcesses must be 1, and only one site may run the app. A second process runs a second scheduler.
Overnight schedules never runidleTimeout is not 00:00:00, or startMode is not AlwaysRunning; or the API service is stopped.
Results vanish mid-page: "no longer available"An overlapping recycle cleared the result files, or the app restarted. Set disallowOverlappingRotation and turn off periodic recycles (app pool).
Runs stuck at "Running"Left by a process killed before it finished. The scheduler closes these at start; if they keep appearing, the app is not stopping cleanly: check the shutdown ladder.
Writing to a network share failsApplicationPoolIdentity cannot reach shares. Use a domain service account, or a local folder.
Writing to a folder failsThe account the API runs as needs write access to the task's output folder and its archive folder.
The Export button is missingBoth gates must agree: the query must list the format, and the role must hold the matching queries.export… permission. An upgrade closes both.
PDF ignores the Word template's lookNeither LibreOffice nor Word is installed, so the built-in layout is used. Install LibreOffice, or set Export:LibreOfficePath.
A dashboard tile stays empty with a messageThe viewer may open the dashboard but not run that tile's query, or its connection. Grant the query too.

AI assistant

ProblemCheck
No AI buttons appearAi:Enabled is false, Offer the AI assistant is off in System Settings, or the role lacks Use the AI assistant.
AI status: "not answering"Is the task "Jadwal AI (Ollama)" running in Task Scheduler? See C:\Ollama\ollama.log. Ai:BaseUrl must use the port given to the installer.
AI status: "model not installed"Ai:Model must match a name from ollama list exactly, e.g. gemma4:12b.
AI answers take minutesNo GPU in use. Check nvidia-smi, and that ollama ps shows the model on the GPU. On CPU only, use qwen3.5:9b.
A connection is missing from Write with AISwitch on Allow AI for it under Database connections (only for read-only accounts). The default connection also needs Allow AI on the default connection.
The AI's answer is refused as unreadableThe model put sentences into the SQL, or wrote a statement of another kind. Try again, or use a larger model.

Building offline

ProblemCheck
dotnet restore fails offlineThe NuGet cache was not copied to %USERPROFILE%\.nuget\packages, or nuget.config does not point at the offline feed. The QueryRunner needs its own restore.
npm tries to reach the networkMissing --offline, wrong --cache path, or node_modules built for another OS or CPU.
npm ci --offline says a package is missingThe bundle is older than a feature that added packages (Arabic, the SQL editor). Build the bundle again.
The offline machine cannot make a self-contained buildThe bundle was built with a different SDK from the one it ships. Put the script's SDK first on PATH and build it again.

المشكلات وما يُفحص

البدء وتسجيل الدخول

المشكلةما يُفحص
الـAPI لا يبدأهل قاعدة البيانات تعمل؟ هل نص الاتصال في appsettings.json صحيح؟ وبعد الترقية، ظهور ORA-00955 أو ORA-01430 في السجل يعني أن تعديل المخطط توقف في منتصفه: انظر قواعد Oracle واسترجع النسخة الاحتياطية.
فشل تسجيل الدخولهل يصل الخادم إلى مضيف LDAP أو AD؟ هل حساب الربط وأسماء الخصائص صحيحة (sAMAccountName لـAD، وuid لـOpenLDAP)؟
فشل الدخول في حزمة Docker بدأت باسم Bayanوحدات LDAP ما زالت تحمل dc=bayan,dc=local. احذف وحدتي ldap_data وldap_config فقط، ولا تستخدم down -v أبدًا.
كلمات مرور قواعد البيانات المحفوظة غير مقروءةتغيّر Encryption:Key بين نسختين. يجب ألا يتغير أبدًا.
محاولات دخول كثيرة (HTTP 429)الدخول محدود لكل عنوان (Auth:Login:PermitLimit، 10 في الدقيقة افتراضيًا). انتظر دقيقة.
الموقع فارغ أو يعرض 404 (nginx)هل يشير root في nginx إلى مجلد browser/ الخاص بالواجهة؟
طلبات /api تعيد 502 (nginx)هل الـAPI يعمل فعلًا على المنفذ 5000؟
أخطاء CORSيجب أن يطابق Cors:AllowedOrigins العنوان الموجود في المتصفح تمامًا. (غير مستخدم على IIS، حيث كل شيء على عنوان واحد.)

IIS

المشكلةما يُفحص
HTTP 500.19، الإعدادات مقفلةأقسام المصادقة غير مفتوحة: نفّذ أمري appcmd unlock في الدخول بحساب Windows، أو اضبط المصادقة من IIS Manager.
HTTP 500.19 يذكر applicationInitializationخاصية Application Initialization غير مثبّتة، فلا يقرأ IIS ملف web.config. ثبّتها (المتطلب ٢). وهي غير مشكلة الإعدادات المقفلة.
HTTP 500.30 أو 502.5 عند البدءحزمة الاستضافة غير مثبتة، أو المجمّع ليس على No Managed Code، أو تعطّل التطبيق أثناء البدء: انظر Event Viewer ← Application وlogs\.
فشل Import-Module WebAdministrationأدوات وسكربتات إدارة IIS غير مثبتة: Install-WindowsFeature Web-Scripting-Tools.
الدخول بحساب Windows يطلب كلمة مرورفُتح الموقع بعنوان IP بدل اسم المضيف، أو المضيف ليس في منطقة الإنترانت المحلية، أو لا يوجد SPN لحساب المجمّع المخصص.
يظهر نموذج الدخول على جهاز في النطاقAuth:EnableSso ما زال false، أو سجّل المستخدم خروجه سابقًا في جلسة المتصفح نفسها (المحاولة التلقائية تنتظر إغلاق المتصفح).

المهام المجدولة والنتائج

المشكلةما يُفحص
كل تصدير مجدول يعمل مرتينأكثر من عملية أو موقع ثانٍ: يجب أن يكون processModel.maxProcesses يساوي 1، وموقع واحد فقط يشغّل التطبيق. فالعملية الثانية تشغّل مجدولًا ثانيًا.
المهام الليلية لا تعمل أبدًاidleTimeout ليس 00:00:00، أو startMode ليس AlwaysRunning؛ أو خدمة الـAPI متوقفة.
تختفي النتائج أثناء التصفح: «لم تعد متاحة»إعادة تدوير متداخلة حذفت ملفات النتائج، أو أُعيد تشغيل التطبيق. فعّل disallowOverlappingRotation وأوقف إعادة التدوير الدورية (مجمّع التطبيقات).
تشغيلات عالقة على «قيد التشغيل»تركتها عملية قُتلت قبل أن تنتهي. يغلقها المجدول عند البدء؛ وإن استمرت بالظهور فالتطبيق لا يتوقف بسلام: افحص سلّم الإيقاف.
فشل الكتابة في مجلد شبكةالحساب ApplicationPoolIdentity لا يصل إلى مجلدات الشبكة. استخدم حساب خدمة في النطاق، أو مجلدًا محليًا.
فشل الكتابة في مجلدالحساب الذي يعمل به الـAPI يحتاج صلاحية الكتابة في مجلد إخراج المهمة ومجلد أرشيفها.
زر التصدير غير موجوديجب أن تتفق البوابتان: أن يذكر الاستعلام الصيغة، وأن يحمل الدور صلاحية queries.export… المقابلة. والترقية تغلق الاثنتين.
ملف PDF يتجاهل شكل قالب Wordلا LibreOffice ولا Word مثبت، فيُستخدم التصميم المدمج. ثبّت LibreOffice، أو اضبط Export:LibreOfficePath.
بطاقة لوحة تبقى فارغة مع رسالةالمشاهد يستطيع فتح اللوحة لكن لا يستطيع تشغيل استعلام تلك البطاقة أو اتصالها. امنحه الاستعلام أيضًا.

المساعد الذكي

المشكلةما يُفحص
لا تظهر أزرار الذكاء الاصطناعيAi:Enabled قيمته false، أو إتاحة المساعد الذكي متوقف في إعدادات النظام، أو الدور لا يحمل استخدام المساعد الذكي.
حالة الذكاء الاصطناعي: «لا ترد»هل المهمة "Jadwal AI (Ollama)" تعمل في Task Scheduler؟ انظر C:\Ollama\ollama.log. ويجب أن يستخدم Ai:BaseUrl المنفذ الذي أُعطي لبرنامج التثبيت.
حالة الذكاء الاصطناعي: «النموذج غير مثبّت»يجب أن يطابق Ai:Model اسمًا من ollama list تمامًا، مثل gemma4:12b.
إجابات الذكاء الاصطناعي تستغرق دقائقبطاقة الرسومات غير مستخدمة. افحص nvidia-smi، وأن ollama ps يُظهر النموذج على البطاقة. وعلى المعالج وحده استخدم qwen3.5:9b.
اتصال غير موجود في «اكتب بالذكاء الاصطناعي»فعّل له السماح للذكاء الاصطناعي في مستخدمي قواعد البيانات (لحسابات القراءة فقط). والاتصال الافتراضي يحتاج أيضًا السماح للذكاء الاصطناعي بالاتصال الافتراضي.
تُرفض إجابة الذكاء الاصطناعي لأنها غير مقروءةكتب النموذج جُملًا داخل SQL، أو كتب جملة من نوع آخر. حاول مرة أخرى، أو استخدم نموذجًا أكبر.

البناء دون إنترنت

المشكلةما يُفحص
فشل dotnet restore دون إنترنتلم تُنسخ ذاكرة NuGet إلى %USERPROFILE%\.nuget\packages، أو nuget.config لا يشير إلى مجلد الحزم. وأداة QueryRunner تحتاج استعادة خاصة بها.
npm يحاول الاتصال بالشبكةينقص --offline، أو مسار --cache خاطئ، أو node_modules مبني لنظام أو معالج آخر.
npm ci --offline يقول إن حزمة مفقودةالحزمة أقدم من خاصية أضافت حزمًا (العربية، محرر SQL). ابنِ الحزمة من جديد.
الجهاز المعزول لا يستطيع البناء المستقلبُنيت الحزمة بإصدار SDK غير الذي تحمله. ضع SDK السكربت أولًا في PATH وابنِها من جديد.

لا نتائج. جرّب كلمة أقصر.
